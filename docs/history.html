- DEVELOPMENT HISTORY

開發歷史

Monster Fusion Masters 並非從線上遊戲開始。它先是一款原創實體策略桌遊，經過多年構想與停滯後，才逐步完成可在瀏覽器遊玩的數位版本。

TIMELINE / 沿革

從實體棋盤到線上對戰

  1. 2020 / PHYSICAL BOARD GAME

    原創實體桌遊公開

    開發者完成 Monster Fusion Masters 的棋盤、六角棋子、玩法、計分與平衡設計，並公開 Monster Fusion Masters V1 3D 列印版本。

  2. AFTER 2020 / DIGITAL IDEA

    數位化構想與暫停

    原作者希望將實體桌遊轉成電子與線上遊戲，但因遊戲程式、多玩家伺服器開發技術與成本門檻，曾嘗試尋求外部開發協助，計畫仍擱置多年。

  3. PROJECT REVIVAL / AI-ASSISTED DEVELOPMENT

    透過 Codex 重新啟動

    隨著 AI 輔助程式開發工具成熟，開發者重新投入專案，利用 Codex 協助將既有遊戲設計實作成軟體、分析程式、除錯與逐步重構。原始遊戲設計、規則及玩法不是 Codex 創造的。

  4. BROWSER PROTOTYPE / DIGITAL GAME

    第一個可玩的數位版本

    實作了棋盤呈現、棋子旋轉與放置、回合、封閉計分、手牌及操作介面，讓原本需要實體棋盤的對局可以在電腦中進行。

  5. ONLINE / MULTIPLAYER

    即時線上多人遊戲

    陸續加入帳號、房間、玩家狀態同步、觀戰等功能。正式線上服務採用 Cloudflare Workers 與 Durable Objects 架構；這些核心程式碼不在公開 Showcase 內。

  6. COMPETITIVE / RANKED & AI

    AI 與競技化

    加入電腦對手、Master AI、Ranked 評分配對、賽季排名、淘汰賽、重播及新手教學，讓單機原型逐步發展為持續營運的線上競技遊戲。

  7. ONGOING / CONTINUED DEVELOPMENT

    持續更新與平衡

    持續改良規則呈現、操作介面、遊戲效能、AI 及多人連線品質。遊戲與玩法方向仍由原作者決定；Codex 是軟體開發的協作工具。

ORIGINAL DESIGN / 原始設計理念

61 格棋盤與棋子配置的設計理念

棋盤大小、棋子的種類與數量比例，以及封閉後的計分方式，是圍繞同一個目標設計的：讓玩家有足夠的時間與空間，嘗試拼出更大的怪物圖形。

BOARD SIZE / 61 CELLS

為什麼選擇 61 格？

實體桌遊初期曾測試少一圈的 37 格棋盤，但實際對局很快就結束，棋子也容易碰到邊界，難以繼續向外延伸或拼出大型圖形。

改採 61 格，是希望讓單局時間維持在約十幾分鐘，同時保留足夠的拼接空間，在遊戲節奏與大型圖形的發展可能性之間取得平衡。

TILES & SCORING / 棋子與計分

為什麼這樣分配棋子？

不同白邊數的棋子並非平均分配；棋子數量比例與封閉計分規則是一起考量的，目的是鼓勵玩家發展大型圖形，而不只是頻繁完成小型封閉。

計分方式刻意讓大型封閉圖形比拆成多個小圖形有更高的得分效率；但延後封閉也意味著要承擔對手干擾、空間受限或無法完成圖形的風險。

策略核心：玩家要選擇立即完成小圖形、先取得分數，還是繼續延伸、追求更大的回報？61 格棋盤、棋子配置與計分方式共同創造了這種取捨。

目前採用的具體規則請參閱棋子與牌庫及封閉計分。

CREATOR / DESIGN OWNERSHIP

遊戲設計與程式協作

Monster Fusion Masters 的核心概念、棋盤設計、棋子規則、計分方式和原始實體版本，均在現代 AI 輔助開發前完成。後續數位版本使用 Codex 參與規劃、實作、除錯與改善流程，但不改變遊戲原始設計的歸屬。
