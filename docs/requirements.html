PLAY / SYSTEM REQUIREMENTS

遊玩與系統需求

Monster Fusion Masters（MFM）是免費線上回合制策略棋盤遊戲，可透過現代瀏覽器或 Windows 的 MFM Desktop 遊玩。

以下是初步硬體相容性參考，不是正式驗證的最低配備。實際效能取決於瀏覽器、硬體、解析度與畫面特效；不保證固定 FPS。

01 / HARDWARE

配備參考

項目基本配備參考建議配備（預估）
CPUIntel Core 第 3 代（僅供實測參考）Intel Core 第 8 代以上（預估）
記憶體8 GB（估算，尚未驗證）16 GB
顯示晶片Intel HD Graphics 4000 等級（實測參考）Intel UHD Graphics 630 等級或以上
解析度1280 × 720（參考）1920 × 1080
網路穩定網際網路連線穩定網際網路連線

基本配備參考表示有接近此級別的電腦曾成功執行遊戲，不代表 8 GB RAM 或所有同級 CPU、GPU 已通過測試；建議配備也不保證能穩定達到 60 FPS。

顯示提示：若螢幕解析度低於 1920 × 1080（1080p），或 Windows 顯示縮放比例設得較大，導致遊戲介面過大或可見空間不足，可至遊戲內「設定（Settings）」調低「UI Scale」，讓介面縮小以顯示更多內容。此調整主要影響介面大小，不保證能提高 FPS。

03 / PERFORMANCE

實際效能參考

開發者的一台舊型筆電配備 Intel Core i7-3520M、Intel HD Graphics 4000、16 GB RAM，螢幕為 1366 × 768。使用 MFM Desktop（WebView2）時，一般畫面約 30 FPS，大量特效時曾下降到約 16 FPS。

這是單一設備與場景的觀察，不是性能保證，也沒有驗證 8 GB RAM 的配備。遊戲提供的 30／60／120 FPS 動畫選項只設定更新率上限，不代表硬體一定能達成對應幀率。

如果畫面不夠流暢，可先嘗試 30 FPS 動畫模式、降低解析度及減少背景程式；Firefox 若表現不佳，也可以試試 Chromium 系列瀏覽器或桌面版。
