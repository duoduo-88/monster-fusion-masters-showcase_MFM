# Wiki game illustrations

These assets are local crops and animation exports of Monster Fusion Masters, captured on 2026-10-16.

- `board`, `tiles-*`, `connection-*`, `score-*`, and `move-*` use the actual game's board and tile renderer. They are controlled demonstration positions, not recordings of another player's private match.
- The seven tile families include the arrangements and center connections displayed by the in-game deck. Illustrated variants are not deck quantities.
- Closure samples were checked by the game's scoring logic: 2 / 3 / 4 / 5 / 6 / 7 distinct tiles earn 1 / 2 / 4 / 7 / 10 / 14 points. Number labels are HTML overlays on the original cropped image.
- `rank-*` uses the current game's CLASSIC badge renderer and effects. The game's public season metadata confirmed `classic-rank-v1` / `CLASSIC` for Season BETA on the capture date. Placement is a separate static status, not a seventh official tier.
- `original-tabletop-2020.webp` is a lightweight WebP export of the author's supplied photograph of the original 3D-printed Monster Fusion Masters V1 tabletop game. It replaces the modern digital-board screenshot in the homepage origin section.
- Other details are crops of the existing public Showcase images: `battle.png`, `lobby.png`, `room.png`, `color-lab.png`, and `showcase-cover.png`. Screens show demonstration data.
- WebP stills support reduced motion, paused playback and no-JavaScript reading. Three GIFs contain the move sequences. Six animated WebP files preserve the badge frame sequences with a smaller download.

No game renderer source, gameplay implementation, account credentials or private capture tools are included. `manifest.json` records dimensions, frame counts and the scoring samples for verification.
