QUICK START / 快速理解

一回合的基本流程

  1. 從手牌選擇棋子。
  2. 旋轉棋子，確認六邊的方向。
  3. 在合法空格落子，讓相鄰邊顏色相符。
  4. 嘗試封閉白色連通區域，取得分數。
ABOUT / 遊戲起源

先有桌遊，才有線上版

MFM 的棋盤、規則、棋子、計分及平衡設計源自開發者的實體桌遊。2020 年公開 3D 列印版本，數年後再透過 Codex 協助將既有設計轉為軟體。遊戲玩法與設計決策仍由原作者負責。
