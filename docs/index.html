03 / 快速上手

一回合，四個步驟

  1. 選擇棋子從手牌選出一枚棋子。
  2. 旋轉方向確認六條邊的排列。
  3. 合法落子讓所有相鄰邊顏色相符。
  4. 封閉得分封閉白色連通區域。
04 / 遊戲起源

先有桌遊，才有線上版

MFM 的棋盤、規則、棋子、計分及平衡設計源自開發者的實體桌遊。2020 年公開 3D 列印版本，數年後再透過 Codex 協助將既有設計轉為軟體。遊戲玩法與設計決策仍由原作者負責。
